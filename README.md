# COUNTERS — League of Legends

**KNOW YOUR ENEMY. WIN YOUR LANE.**

Aplicação web simples, rápida e focada exclusivamente em encontrar o counter perfeito no League of Legends.

## Funcionalidades

- **Todos os Campeões do LoL**: Carrega em tempo real a lista oficial completa com fotos via Riot Data Dragon (`pt_BR`).
- **Seleção Instantânea**: Clique diretamente na foto de qualquer campeão ou digite o nome para filtrar e selecionar com `Enter`.
- **Ranking de Counters (#1, #2, #3)**: Exibe os 3 principais counters por rota com explicação tática do confronto.
- **Cooldowns das Skills (P, Q, W, E, R)**: Mostra os ícones e tempos de recarga reais de cada habilidade do adversário e dos counters (com detalhes ao clicar).

## Executando localmente

```bash
npm install
npm run dev
```

## Build de produção (Vercel)
